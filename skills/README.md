# Agent skills

Install into Cursor, Claude Code, Codex, and other agents:

```bash
npx skills add Aris-ngoy/NitroWind
npx skills add https://nitro-wind.mintlify.app
```

| Skill | When to load |
| --- | --- |
| [`nitro-wind`](nitro-wind/SKILL.md) | New installs, `className`, theming, animations, API |
| [`migrate-to-nitro-wind`](migrate-to-nitro-wind/SKILL.md) | Replacing NativeWind, Uniwind, Unistyles, or another styling library |

These directories are the source of truth. Mintlify serves the same files via `docs/.mintlify/skills`.
