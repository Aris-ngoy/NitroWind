---
title: "Migrate from Uniwind"
description: "Remove Uniwind's Metro CSS pipeline. Keep className, withUniwind, and uw-* animation tokens."
keywords: ["uniwind", "migration"]
---

Uniwind and nitro-wind both use Tailwind `className`. You drop the CSS entry, `withUniwindConfig`, and `extraThemes`. Compatibility aliases keep existing call sites compiling.

<Prompt description="Migrate this React Native app from Uniwind to nitro-wind." actions={["copy", "cursor"]}>
Install the nitro-wind agent skills, then migrate this project from Uniwind to nitro-wind.

npx skills add Aris-ngoy/NitroWind

Follow the migrate-to-nitro-wind skill. Remove uniwind, add nitro-wind and react-native-nitro-modules, delete withUniwindConfig from Metro, replace Uniwind providers with NitroWindProvider, and point remaining uniwind imports at nitro-wind. withUniwind, useUniwind, and uw-* tokens keep working.
</Prompt>

<Steps>
  <Step title="Replace the packages">
    ```bash
    npm uninstall uniwind
    npx expo install nitro-wind react-native-nitro-modules
    ```

    Leave `tailwindcss` only if the web target still uses it.
  </Step>
  <Step title="Remove withUniwindConfig">
    Delete the Uniwind Metro wrapper (`cssEntryFile`, `polyfills.rem`, `extraThemes`, `dtsFile`). Export the default Expo or RN Metro config. Add `plugins: ["nitro-wind/babel"]`.
  </Step>
  <Step title="Stop importing global.css">
    Remove the native `import "./global.css"` and Metro CSS wrapper. Keep the `@theme` block — nitro-wind reads it from `global.css` without importing the file. See [Theme config](/guide/tailwind-config). Named modes stay as `premium:` prefixes or `NitroWind.updateCSSVariables`.
  </Step>
  <Step title="Swap the provider">
    ```tsx
    import { NitroWindProvider, NitroWind } from "nitro-wind";

    <NitroWindProvider>{children}</NitroWindProvider>
    NitroWind.setTheme("dark");
    ```

    `Uniwind` is an alias of `NitroWind`. `withUniwind` is an alias of `withNitroWind`. `useUniwind` and `useResolveClassNames` are still exported. Prefer the nitro-wind names in new files.
  </Step>
  <Step title="Keep className and motion tokens">
    Babel-mapped hosts keep `className`. Use `styled()` for other hosts. `uw-entering-*` / `uw-exiting-*` / `uw-layout-*` keep working (`nw-*` is the same set). See [Animations](/guide/animations).
  </Step>
  <Step title="Replace insets helpers">
    There is no `Uniwind.updateInsets` and no `pt-safe`. Use `styled(SafeAreaView)` or `useSafeAreaInsets()`.
  </Step>
</Steps>

Delete `uniwind-types.d.ts`. Change remaining `from "uniwind"` imports to `from "nitro-wind"`. Rebuild after the first native install.

Full agent checklist: the `migrate-to-nitro-wind` skill in [`skills/`](https://github.com/Aris-ngoy/NitroWind/tree/main/skills/migrate-to-nitro-wind).
