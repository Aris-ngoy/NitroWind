---
title: "Migrate from Uniwind"
description: "Point Uniwind providers and className usage at nitro-wind."
keywords: ["uniwind", "migration"]
---

Swap Uniwind's runtime for `nitro-wind`:

- Replace Uniwind providers with `NitroWindProvider`.
- Keep `className` on Babel-mapped React Native hosts (`View`, `Text`, `FlatList`, …). Use `styled()` for other hosts or third-party components. See [Styling with className](/guide/styling).
- Entering / exiting / layout tokens (`uw-entering-*`, `uw-layout-*`) keep working. See [Animations](/guide/animations).
- Theme tokens follow Tailwind defaults (colors, spacing, radii). Custom Uniwind themes can be re-expressed with `dark:` variants or by extending `nitro-wind-core` token tables.

`Uniwind` is exported as an alias of the `NitroWind` singleton, so existing `Uniwind.setTheme(...)` calls can keep compiling while you migrate.
