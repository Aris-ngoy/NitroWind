---
title: "Migrate from NativeWind"
description: "Swap NativeWindProvider and cssInterop for nitro-wind styled() and the Babel plugin."
keywords: ["nativewind", "migration", "cssInterop"]
---

<Steps>
  <Step title="Install">
    Install `nitro-wind` and `react-native-nitro-modules`.
  </Step>
  <Step title="Replace the provider">
    Replace `NativeWindProvider` with `NitroWindProvider`.
  </Step>
  <Step title="Keep className">
    Enable the Babel automapping plugin so `View`, `Text`, `FlatList`, and the other mapped hosts accept `className` from `react-native`:

    ```js
    plugins: ["nitro-wind/babel"]
    ```

    Use `styled()` only for hosts the plugin does not remap, or for third-party components. See [Styling with className](/guide/styling).
  </Step>
  <Step title="Drop cssInterop">
    Most Tailwind layout, spacing, color, and typography utilities work unchanged. NativeWind-specific `cssInterop` calls are unnecessary — `styled()` maps `className` onto the `style` prop.
  </Step>
</Steps>
