## `NitroWindProvider`

Provides theme, platform, and group/interaction context. Window size is not in this context — `useStyle` subscribes to dimensions only when the className has breakpoint variants.

## `useStyle(className)`

Returns `{ style, animation, native }`. `style` is already inflated (`shadowOffset`, `transform`) and `animation` is already parsed — callers do not inflate or re-tokenize. Invariant classNames skip theme and layout subscriptions.

## `styled(Component)`

Adds a `className` prop, merges with `style`, forwards refs, and enables `group-*` variants when the `group` class is present. Also maps extra `*ClassName` props (`contentContainerClassName` → `contentContainerStyle`). Use it for hosts the Babel plugin does not remap, or any third-party component that accepts `style`.

See [Styling with className](/guide/styling).

## Babel plugin (`nitro-wind/babel`)

Rewrites these `react-native` imports to `nitro-wind` so `className` works without `styled()`: `View`, `Text`, `Pressable`, `Image`, `ScrollView`, `TextInput`, `TouchableOpacity`, `FlatList`. Invariant static `className` literals are hoisted into `StyleSheet.create`.

If `global.css` contains `@theme` or `tailwind.config.js` is present (or you pass `{ css, config }`), the plugin registers those tokens before hoisted styles resolve. Details: [Theme config](/guide/tailwind-config).

## Pre-styled components

Import any of these from `nitro-wind` (each also has a `Styled*` alias):

`View`, `Text`, `Pressable`, `Image`, `ImageBackground`, `ScrollView`, `TextInput`, `TouchableOpacity`, `TouchableHighlight`, `TouchableWithoutFeedback`, `TouchableNativeFeedback`, `FlatList`, `SectionList`, `VirtualizedList`, `Switch`, `ActivityIndicator`, `Button`, `RefreshControl`, `KeyboardAvoidingView`, `Modal`, `SafeAreaView`.

The Babel plugin remaps `View`, `Text`, `Pressable`, `Image`, `ScrollView`, `TextInput`, `TouchableOpacity`, and `FlatList` from `react-native`, so those eight do not need a `nitro-wind` import. Full table and extra `*ClassName` props: [Supported components](/guide/styling#supported-components).

## Engine

| Function | Purpose |
| --- | --- |
| `computeStyle(className, context)` | Native Nitro path with JS fallback |
| `computeStaticStyle(className)` | Inflated style dictionary for Babel `StyleSheet.create` hoisting |
| `isNativeEngineAvailable()` | Whether the C++ HybridObject loaded |
| `clearEngineCache()` | Drop cached style results |
| `setEngineThemeName(name)` | Update the engine-side theme name |

## `NitroWind` singleton

```ts
import { NitroWind, ThemeTransitionPreset } from "nitro-wind";

NitroWind.setTheme("dark", { preset: ThemeTransitionPreset.Fade });
NitroWind.getTheme();
NitroWind.updateCSSVariables("dark", { "--accent": "#4F46E5" });
NitroWind.getCSSVariable("--accent");
NitroWind.loadTailwindCss(`@theme { --color-brand: #4F46E5; }`);
NitroWind.loadTailwindConfig(require("./tailwind.config.js"));
```

`Uniwind` is an alias of `NitroWind` for drop-in migrations.

`useCSSVariable`, `ScopedTheme`, and `ScopedVariables` are documented under [Theming basics](/guide/theming) and [Custom themes](/guide/custom-themes).
